Guia Ionic

Seu Primeiro App!

Neste mini-curso prático, você vai aprender a dar os primeiros passos no desenvolvimento mobile criando um aplicativo real, do zero à publicação.

O que é o Ionic? O Ionic é um framework poderoso que permite criar aplicativos para Android e iOS utilizando as tecnologias web que você já estuda: HTML, CSS e Angular/TypeScript. Você escreve o código uma vez e ele funciona em qualquer lugar! O que vamos aprender? Nas próximas abas, vamos preparar o seu computador instalando ferramentas essenciais como o VS Code e o Node.js. Depois, vamos executar comandos no terminal para construir a sua interface.
