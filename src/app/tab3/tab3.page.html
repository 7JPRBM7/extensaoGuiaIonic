Criando o seu App

Abra o terminal na pasta onde deseja salvar o seu projeto e siga estes 3 comandos.

1

Criar o Projeto

 O comando inicial baixa toda a estrutura base do ecossistema. Digite no terminal:
ionic start meu-primeiro-app blank --type=angular
1.1 Nome do App: meu-primeiro-app define o nome da pasta física que será gerada no seu computador.
1.2 O Template: blank avisa que queremos um layout limpo e em branco, ideal para construir do zero sem códigos de exemplo poluindo o projeto.
1.3 O Tipo: --type=angular configura o projeto para usar a estrutura do Angular baseada em TypeScript.
1.4 Arquitetura: Durante o processo, o terminal perguntará se deseja usar a arquitetura Standalone ou NgModules. Escolha Standalone, pois ela dispensa os antigos NgModules e deixa o app mais leve.
2

Acessar a Pasta

 Depois que o download terminar, você precisa navegar para dentro da pasta criada antes de rodar qualquer outro comando:
cd meu-primeiro-app
3

Rodar o Aplicativo

 Tudo pronto! Este comando compila o código, ativa o servidor local e abre o app em tempo real no seu navegador padrão.
ionic serve

Parabéns!

Você acaba de dar o seu primeiro passo no mundo do desenvolvimento mobile.
