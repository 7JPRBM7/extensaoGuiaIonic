Preparando o Terreno

Configuração Inicial

Siga estes 3 passos simples para deixar seu computador pronto para programar.

1

Instale o Node.js

 O Node.js é o motor que vai rodar o nosso ambiente por trás dos panos. Acesse o site oficial (nodejs.org) e baixe a versão recomendada (LTS). 2

Baixe o VS Code

 Ele será o nosso editor de código. É nele que vamos escrever e organizar os arquivos do aplicativo. É gratuito e muito leve! 3

Instale o Ionic CLI

 Com o Node.js instalado, abra o terminal do seu computador e digite o comando abaixo para instalar as ferramentas do Ionic globalmente:
npm install -g @ionic/cli
