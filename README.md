# 🚀 Guia Ionic - Primeiros Passos

Este projeto é um miniaplicativo educacional desenvolvido para guiar estudantes iniciantes na configuração e criação do seu primeiro projeto mobile. Ele foi construído com foco em clareza, design minimalista e usabilidade.

## 🎯 Objetivo do Projeto
Desenvolvido como parte do **Projeto de Extensão** da disciplina de Desenvolvimento Mobile. O objetivo central é disseminar o conhecimento tecnológico, ensinando de forma prática como configurar o ambiente de desenvolvimento e executar os primeiros comandos no terminal utilizando boas práticas de versionamento.

## 📱 Estrutura do Aplicativo
O aplicativo utiliza o template de navegação por abas (Tabs) e está dividido em 3 etapas de aprendizado:

* **Tab 1 (Introdução):** Apresentação do projeto e explicação sobre o que é o framework Ionic.
* **Tab 2 (Material):** Guia de configuração do ambiente, cobrindo a instalação do Node.js, VS Code e Ionic CLI.
* **Tab 3 (Prática):** Passo a passo interativo detalhando os comandos `ionic start`, navegação de pastas e `ionic serve`, com subetapas explicativas.

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Ionic Framework:** Construção da interface e componentes UI.
* **Angular (Standalone):** Lógica e roteamento sem a necessidade de NgModules.
* **SCSS:** Estilização padronizada com variáveis CSS.
* **Git e GitHub:** Versionamento contínuo e hospedagem do código-fonte.
* **VS Code:** Ambiente de desenvolvimento integrado.
